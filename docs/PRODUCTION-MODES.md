# Production Modes｜三档生产模式 v0.7

事实、Scope、版权、隐私门槛在所有模式中相同。模式差异主要在速度、研究深度、作者竞争、清晰度与独立盲审强度。

## Flash｜抢热点
适用：当天突发、窗口短、主要价值是快速解释。

最小链路：
`TopicHunter → ResearchPack Lite → ViralWriter → VisualEditor → PublisherQA → PublishingPlan`

Flash 可跳过完整 AuthorLens / ArticleArchitect / BlindReview，但必须有：
- 具体入口；
- 明确判断；
- 基本 Reader Promise；
- 标题承诺与正文交付一致；
- 不降低事实门。

如果标题本身承诺“哪些/怎么做/清单”，Flash 也不能用新闻摘要代替答案。

## Standard｜标准文章
适用：日常主力。

链路：
`TopicHunter → ResearchPack → AuthorLens → ArticleArchitect → ViralWriter → BlindReview → VisualEditor → PublisherQA → PublishingPlan`

要求：
- Tension Test=pass；
- Reader Promise Test=pass；
- delivery_potential 不得 low；
- exclusive material path 或 strong judgment candidate 至少一个成立；
- 完整 Evidence / Uncertainty Ledger；
- Originality ≥1A 或 ≥2B；
- AuthorLens 生成3个POV并淘汰2个；
- POV 同时评价 reader_value / specificity / frameworkability / evidence_strength；
- selected POV 生成可直接回答标题的 provisional_core_answer；
- 材料墓地 discarded_units ≥ retained_units；
- Architect 冻结 Reader Contract / Delivery Units / Thesis Prominence；
- `which/how/list` 默认使用清晰编号框架；
- Writer 先兑现第一屏与标题承诺，再分段生成；
- Clarity Pass 必须通过；
- BlindReview 必须 fresh_session 或 different_model；
- BlindReview 未通过不得进入 VisualEditor。

## Deep｜深度旗舰
适用：亲测、调查、商业拆解、长期品牌内容。

链路同 Standard。

额外要求：
- Originality ≥1A+1B；
- 更强的一手/独家材料；
- selected POV 必须被A级材料改变或约束；
- 深度不能牺牲 Reader Contract；
- 强叙事若延迟核心结论，必须显式记录 delayed_reason；
- 盲审建议优先 different_model；
- 不追求日更。

## 模式选择
优先根据：
1. 热点剩余窗口
2. 是否有真正张力
3. Reader Promise 是否具体
4. 能否形成3–5个清晰交付单元
5. 是否能得到独家材料或形成强判断
6. 证据复杂度
7. 账号价值与文章寿命

如果只有“热点+公开资料+第二显然观点”，应降为 Flash/backup。

如果观点很深但 frameworkability / specificity 很低，也不应硬做 Standard/Deep；公众号不是思想备忘录，必须让读者看得懂、拿得走。
