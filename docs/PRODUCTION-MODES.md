# Production Modes｜三档生产模式 v0.5

事实、Scope、版权、隐私门槛在所有模式中相同；差异只在研究深度、作者层完整度、结构复杂度、原创资产要求和速度。

## Flash｜抢热点
适用：当天突发、窗口短、需要快速解释。

目标：通常1000–1500字。

最小链路：
`TopicHunter → ResearchPack Lite → ViralWriter → VisualEditor → PublisherQA → PublishingPlan`

Flash 可以跳过完整 AuthorLens / ArticleArchitect，但不能完全没有作者选择。进入 Writer 前至少明确：
- 一个具体入口
- 一个明确判断
- 哪些背景不写

要求：
- 3–5条关键 Claim 即可，但标题/导语主张必须 verified/title_safe。
- Competition Scan 可 partial，但不得伪装成全网结论。
- Originality Gate 可 conditional。
- 不为了赶时效降低 Scope、Evidence、版权和隐私标准。
- 不因为“快讯”就自动写成标准 What/Why/How 摘要。

## Standard｜标准文章
适用：日常主力文章。

目标：通常1200–2500字，按信息价值浮动。

链路：
`TopicHunter → ResearchPack → AuthorLens → ArticleArchitect → ViralWriter → VisualEditor → PublisherQA → PublishingPlan`

要求：
- 完整 Evidence Ledger。
- Originality 至少 `1×A` 或 `2×B`。
- AuthorLens 必须完成 POV、具体入口、材料取舍、Narrative Choice、Voice Profile。
- 关键章节 Claim/Calc 绑定。
- ViralWriter 必须完成 Anti-Template Pass。
- 完整视觉资产和发布计划。

## Deep｜深度旗舰
适用：亲测、调查、商业拆解、长期品牌内容。

目标：2500–5000字或按信息价值延长。

链路同 Standard，但 AuthorLens 和原创要求更强。

要求：
- 更广竞争扫描和反方证据。
- Originality 至少 `1×A + 1×B`。
- A级原创资产必须进入核心论证。
- AuthorLens 必须说明A级材料如何改变作者判断或叙事入口。
- 可增加实验、访谈、复现、数据集。
- 不追求日更，目标是建立常读与品牌资产。

## 模式选择
优先根据：
1. 热点剩余窗口
2. 证据复杂度
3. 是否有一手素材
4. 是否需要强作者判断
5. 账号价值
6. 预计文章寿命

不要因为素材不够就把 Deep 降成 Flash 来绕过事实门；也不要因为 Standard 有完整流程，就把文章写成结构完整但作者缺席的说明文。
