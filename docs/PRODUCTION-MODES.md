# Production Modes｜三档生产模式

事实、Scope、版权、隐私门槛在所有模式中相同；差异只在研究深度、结构复杂度、原创资产要求和速度。

## Flash｜抢热点
适用：当天突发、窗口短、需要快速解释。

目标：1000–1500字。

最小链路：
`TopicHunter → ResearchPack Lite → ViralWriter → VisualEditor → PublisherQA → PublishingPlan`

要求：
- 3–5条关键 Claim 即可，但标题/导语主张必须 verified/title_safe。
- Competition Scan 可 partial，但不得伪装成全网结论。
- Originality Gate 可 conditional。
- 不为了赶时效降低 Scope、Evidence、版权和隐私标准。

## Standard｜标准爆款
适用：日常主力文章。

目标：1500–2500字。

链路：
`TopicHunter → ResearchPack → ArticleArchitect → ViralWriter → VisualEditor → PublisherQA → PublishingPlan`

要求：
- 完整 Evidence Ledger。
- Originality 至少 `1×A` 或 `2×B`。
- 关键章节 Claim/Calc 绑定。
- 完整视觉资产和发布计划。

## Deep｜深度旗舰
适用：亲测、调查、商业拆解、长期品牌内容。

目标：2500–5000字或按信息价值延长。

要求：
- 更广竞争扫描和反方证据。
- Originality 至少 `1×A + 1×B`。
- A级原创资产必须进入核心论证。
- 可增加实验、访谈、复现、数据集。
- 不追求日更，目标是建立常读与品牌资产。

## 模式选择
优先根据：
1. 热点剩余窗口
2. 证据复杂度
3. 是否有一手素材
4. 账号价值
5. 预计文章寿命

不要因为素材不够就把 Deep 降成 Flash 来绕过事实门。
